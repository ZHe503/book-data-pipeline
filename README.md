# Book Data Pipeline

A small python project that pulls an apipulls book data from the Open Library Api, processes the returned JSON daata, handles missing valuues, and stores cleaned results in a CSV file.

## Features

- Search for books using the Open Library Api
- Extract book titles, authors, and publication years
- Handle missing data and empty search results
- Store cleaned book data in CSV format

## Technologies

- Python
- Requests
- Open Library API
- Git and GitHub
